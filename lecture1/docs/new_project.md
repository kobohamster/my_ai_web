# New Project Guide

> 이 파일은 플레이스홀더입니다. 실제 프로젝트 준비 문서로 교체해주세요.

## 새 프로젝트 시작하기

1. `_template_settings` 디렉토리 복사
2. 프로젝트 이름으로 변경
3. `package.json`의 name 업데이트
4. `npm install` 실행
5. 개발 서버 시작: `npm run dev`

## 필수 패키지
- react + react-dom
- react-router-dom
- @mui/material + @emotion/react + @emotion/styled
- @mui/icons-material
- @fontsource/roboto
