# Lecture1 프로젝트 설정

## 역할 설정
- 이 디렉토리는 React 학습 프로젝트를 위한 공간입니다
- MUI 기반 컴포넌트 개발을 지원합니다

## 문서 연결
- @docs/design-system.md
- @docs/code-convention.md
- @docs/new_project.md

## 개발 환경
- Vite + React
- MUI (Material-UI) v5+
- React Router DOM

## 주의사항
- 새 프로젝트 시작 시 `_template_settings` 디렉토리를 복사하여 사용
- 모든 컴포넌트는 MUI 컴포넌트를 우선 사용
- 테마는 `src/theme.js`에서 중앙 관리
